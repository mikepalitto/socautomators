Ingestion Patterns

Analytics Tier
All events to Analytics for real-time detection. Data mirrors to Data Lake via continuous export (delayed).
Data Lake
All events to Data Lake only. Queryable for forensics and hunting — no real-time alerting.
Dual-Ingest
Active DCR split. Alert-grade events → Analytics for real-time detection. Full raw stream → Data Lake for forensics and hunting.
Analytics Mirror
Analytics data replicates to Data Lake via continuous data export rules (minutes-to-hours delay). Not a real-time split.

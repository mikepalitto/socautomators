# The Agentic SOC on Microsoft Sentinel — Companion Code

Companion code and reference material for the **Agentic SOC on Microsoft Sentinel** series on [socautomators.substack.com](https://socautomators.substack.com).

The series teaches how to build, operate, and sell an agentic SOC on the Microsoft Security Platform — Sentinel as substrate, Defender XDR for endpoint and identity, Purview for governance, Entra for identity, Foundry for the agent runtime, Security Copilot and the Security Store for out-of-the-box and partner agents, Agent 365 for governance.
